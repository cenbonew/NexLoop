# ADR-036｜Object Set：只读、受治理发布、读取时求值

状态：**采用**。负责人 2026-10-20 在能力差距分析中决定 D-G2 按推荐执行（`docs/implementation/eios-capability-gap.md` §2.1、§4）。

关联：

- ADR-007（不让 Evo 成为第二事实库）；
- ADR-019（候选定义人工审核）；
- ADR-025、ADR-035（工作台成员读取）；
- AT-003（没有 READ 时字段不可见）；
- NX-029（删除传播）；
- vendored 契约 `eios/ontology/definitions.py:1781`（`ObjectSetDefinition`）。

## 1. 背景

EIOS 的 Object Set 是一个保存起来的查询：一个对象类型，加上属性过滤、排序和投影。NexLoop 已经 vendored 了它的定义契约，但没有表、求值和页面。目标人群、外联候选和审核范围都需要“可以复用、可以审计的对象范围”。上游的执行器在内存中求值，还可以把成员冻结成 revision 快照；这两点都不适合 NexLoop 的权限模型和删除传播。

## 2. 决定

1. **只读**：Object Set 不写任何对象，也不触发任何效应；求值的结果只是一份对象 ID 列表和计数。
2. **定义契约**：只使用 vendored 的 `ObjectSetDefinition`。存储的定义按它的字段名保存，并且必须能被这个契约校验通过。本期只开放以下部分：
   - `object_type`；
   - `filters`：只用常量操作数，操作符为 eq、ne、gt、gte、lt、lte、in、not_in；
   - `sort`；
   - `projection`；
   - `snapshots_allowed` 恒为 false。

   参数、Link 遍历、聚合和语义搜索本期不开放，出现即拒绝。
3. **发布**：
   - **选择受治理的人类 Action，不选可信配置。** 理由是 Object Set 是租户自己的业务定义，与目标、指标、外联目的的开关同类，后者都走负责人的受治理 Action。可信配置用于随发布版本下发的系统目录（Action、Function、系统类型），需要部署操作，不适合租户日常调整。
   - 具体做法：
     - Action `nexloop.object_set.publish:1`（capability `object_set.publish`，operation `publish_object_set`），只限负责人；
     - 每次发布生成同名定义的下一个版本，版本不可修改、不可删除；
     - 意图、发布人、原因与时间都被记录，审计复用受治理入口和意图记录。
4. **求值在 SQL 中、读取时进行，不保存成员快照**：
   - 每次读取都按当前数据重新求值；
   - 不保存成员列表，所以删除传播不会遗漏副本；
   - 需要冻结时（例如今后的评估或外联批次），只记录结果 digest。
5. **权限不放大**：
   - 过滤和排序只能使用**已声明属性组、且该组未被负责人标为受限**的属性。发布时检查一次；求值时再检查一次，如果负责人后来把组标为受限，整个 Object Set 返回 `withheld`，不求值。没有属性组的属性（例如系统类型的属性）本期不能用于过滤。
   - 求值只给出候选。每个对象由工作台按 ADR-025、ADR-035 的成员派生逐个核对 READ（读取审计，用途 `object_set`）：读不到的只计入“不可见”，不列出。
   - 投影属性逐个按属性 READ 读取，读不到的显示为 `withheld`，不显示值。
   - 计数是候选总数，与 W2 实例浏览中的 `total` 口径相同；页面同时显示不可见数。
6. **不成为第二事实库**：定义只是查询，不保存业务值，不保存成员；业务事实只在 `ontology.objects` 中，经受治理 Action 改变（ADR-007）。
7. **今后的引用**：目标人群、外联候选和审核范围可以按 (stable_name, version) 引用一个 Object Set。引用方在使用时自行求值，并遵守自己的 READ 和派发闸门。本期只提供只读页面与预览，不接入任何派发路径。

## 3. 后果

- 负责人可以定义可复用的对象范围，所有成员都能在权限范围内预览。
- 过滤条件受限于“有属性组且未受限”的属性。要对系统类型做过滤，需要另行决定这些类型的属性组。
- 求值是在线计算；预览分页的上限是偏移 1000、每页 50。大范围的批量使用要等引用方设计时再定。
