```sh

uv run --frozen python scripts/community_test.py verify --output .ci-results/my-fresh-community-test
uv run --frozen python scripts/community_test.py run --output .ci-results/my-fresh-community-test

Never use the repository root as a build context. The root .dockerignore fails closed.
