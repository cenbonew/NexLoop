# NexLoop brand assets

- `nexloop-logo.png`: approved folded N and NexLoop horizontal wordmark, transparent raster. Used by the shared Brand component and both project READMEs.
- `nexloop-mark.png`: standalone folded N, transparent square PNG. Used for browser and touch icons.

The project owner selected and approved this identity on 2026-10-16. Assets were prepared with built-in image generation from that approved design. Preserve aspect ratio, allow clear space, and use a light backing for the navy wordmark on dark surfaces. These are PNG masters, not editable vector artwork.
