**用途**：10/20 生成 v0.1 验收证据包（[骨架](at-015-evidence-pack.md)），并填写 [NX-037 验收报告模板](nx037-acceptance-report.template.md)。

**名称说明**：调度员把这一步叫“AT-015”。planning 里的 AT-015 是“SSE 恢复”，已经 passed。本单讲的是 v0.1 整体验收证据包，核心对象是 AT-071（受控真实模型与真实交付），同时汇集 S5 各 AT 的证据。

## 2. 生成证据包（管理机，A 类）

```
cd "$RELEASE_CHECKOUT"
PYTHONPATH=packages/eios-core/src python3 scripts/nx037/evidence_pack.py --out "$PACK" \
  --trial "$EV/trial" \
  --item release_manifest="$EV/release/manifest-10.json" --item ci_result="$EV/release/ci-result-10.json" \
  --item inventory_before="$EV/environment/inventory-before-app.json" --item inventory_after="$EV/environment/inventory-after-app.json" \
  --item restore_drill="$EV/backup-restore/restore-<drill-id>.json" --item effect_reconciliation="$EV/effects/reconciliation.json" \
  --item load_report="$EV/load/report.json" --item third_party_notices="$EV/release/THIRD_PARTY_NOTICES.md" \
  --item public_preflight="$EV/release/public-preflight.json" --item known_risks="$EV/known-risks.md"
PYTHONPATH=packages/eios-core/src python3 -c 'import sys; sys.path.insert(0,"scripts/nx037"); import evidence_pack as e; print(e.check(sys.argv[1]))' "$PACK"
```

- **预期**：
  - 第一条输出 `{"ok": true, "present": [...], "missing": [...]}`。`missing` 只能是确实没有的项，例如没有运行 public-preflight 时的那一项；
  - 第二条输出 `[]`：包内只有允许的值。
- **产物**：
  - `index.json`；
  - `release.json`：清单的固定字段；
  - `interactions/summary.json`：按类型、按结局的计数，时间分解的 p50/p95，费用，停止与暂停结论，`test_stack` 与 `persona`；
  - `interactions/reconciliation.json`；
  - `interactions/records.json`：经值过滤的逐条记录；
  - 有 `consent.json` 时还有 `interactions/participants.json`。
- **CLI 没有 `check` 子命令**：`check()` 只是一个函数，所以用上面第二条的方式调用。
- **退出码**：0 成功；1 读写或取值错误，只输出错误类型；2 输出目录已存在。

## 5. 离线验证结果（本地合成数据，2026-10-17）

- **过程**：
  1. `run_interactions.py --driver synthetic` 在临时目录生成一个 30 次的合成试运行，`status: completed`；
  2. 用 `--void-seq 30 --void-confirmation <合成引用>` 作废最后一条并重做；

- **结果**：
  - 输出 `ok: true`；`present` 为 interactions、known_risks、release_manifest、restore_drill，其余 7 项为 missing；
  - 包内 5 个文件：`index.json`、`release.json`、`interactions/summary.json`、`interactions/reconciliation.json`、`interactions/records.json`；
  - `check()` 返回 `[]`；

  - 清单中的自由文本字段被置为 null。
- **复现了 R1–R3**：
  - 实际格式的 release id 不被允许；

- 合成数据只用于确认证据包的输出结构，不是任何 AT 的证据。
