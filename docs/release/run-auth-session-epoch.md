# 运行单：浏览器会话绑定 session_epoch（AUTH-DOS，stage）

- 适用分支：`l7/auth-dos`，基于第 110 批 79456af6。迁移 0404（临时号，调度员合批时重编）。ADR-044。
- 内容：会话检查（`control.nexloop_read_browser_session`、`authz.nexloop_browser_identity_snapshot`）不再比较账户 `revision`，也不再因锁定拒绝已有会话（负责人 2026-11-02）；账户指纹不再含 `revision`、`lockout_level`、`locked_until`；`session_epoch` 及其余检查不变。
- 执行者：调度员。判定者：L6。

## 上线影响

- 与 AUTH-FP 相同：迁移生效时，在途的浏览器 claim 因账户指纹变化被拒一次，前端重读、SSE 自动重连，不登出会话。
- 生效后：他人输错密码不再让该账户的会话失效；锁定（第 5 次失败起）只拒绝新的密码登录，已有会话不受影响。要踢会话，走改密码或重置。

2. 验证（只用合成测试账号，不碰真实用户）：

   - 回到 A 的页面刷新：仍然登录、页面可读。
