# 执行单 4.6“部署后清点”只读命令单（2026-10-15）

部署日执行单 4.6 的落地版本。**本单全部是只读操作**：不改任何文件、容器、规则或数据库，也不读任何秘密的内容。

- **只用角色名与参数**：
  - `$RID` = `20261014-76df1926d6c0-1`（commit 76df192）；
  - `$RELEASE_ROOT`、`$NEXLOOP_ROOT`、`$EVIDENCE_DIR`、`$PLAN_DIR_APP`、`$PLAN_DIR_DATA`、`<PG_CONTAINER>`、`<METRICS_DSN_FILE>` 的取值都在负责人的私有 env 中。
- **执行者**：
  - 只读命令由调度员提交，在负责人开的交互会话中执行；
  - 需要 sudo 的只读命令（`nft`、`ufw`、`cryptsetup status`、对秘密目录的 `stat`），在 DATA_HOST 上由负责人输入 sudo，在 APP_HOST 上逐步授权。
- **输出**：每条命令的输出存入 `$EVIDENCE_DIR/run46/`（0600）。其中含主机上的服务名与路径，属于私有证据，不进仓库；回填 planning 时只写下文 §8 的摘要形式。
- **不符时**：本单不做任何修复。表中“不符时”一栏只写判断与上报方式，修复按对应的运行手册另行逐步授权。

## 2. 容器与镜像 digest 对照发布清单

```
python3 scripts/release/archive.py check --root "$RELEASE_ROOT" --release-id "$RID" --allowed-signers "$ALLOWED_SIGNERS"
python3 -c 'import json,sys; m=json.load(open(sys.argv[1])); [print(i["name"], i["reference"]) for i in m["images"]]' "$RELEASE_ROOT/releases/$RID/manifest.json"
cat "$PLAN_DIR_APP/compose.images.env" "$PLAN_DIR_DATA/compose.images.env"
```
