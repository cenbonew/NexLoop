# NexLoop v0.1.0-rc 发布说明（草稿）

[English](v0.1.0-rc-notes.md) | 简体中文

> **草稿。** 这是候选版本。打 tag 和发布 GitHub Release 只能由负责人本人执行；验收摘要和已知限制在打 tag 前由维护者更新。本文不描述任何已经发生的部署。

## v0.1 是什么

NexLoop 是面向企业的开源**持续运营系统**：负责人设定目标与关键结果，Agent 在受治理的 Action 边界内理解消费者、履行承诺、交付价值，并根据真实结果调整计划。

v0.1 是**受控真实闭环**：一个租户、一种真实交互渠道（原生 WebChat）、一次真实交付动作、一个受控真实模型；**真实动作的可靠性优先于**消费者数字孪生和模拟选优。本候选版本在受控真实闭环验收（NX-037）**之前**发布；验收完成后再打正式的 `v0.1.0`（负责人决定 D-d）。

项目仍在探索阶段，不保证提高收入或付费，接口与数据结构仍会变化。

## 包含的能力

根据 [CHANGELOG](../../CHANGELOG.md) 归纳，架构见 [docs/ARCHITECTURE.md](../ARCHITECTURE.md)。

- **受治理 Action 与可靠性**：只有已发布的 EIOS Action 能改正式业务对象或产生外部效应；稳定的业务意图 ID、持久化后 ACK、结果不明先查询对账再决定；三层真实派发开关（部署、租户、租户与 Action），默认关闭，只有负责人能改。
- **对话到本体**：话题切分与带原文区间的 Claim 提取、混合召回、四层匹配、候选定义的粘合与人工审核。
- **目标、计划与上下文**：版本化的目标与关键结果、控制面（暂停、预算、联系限制、接管）、计划复评、逐来源授权并记录模型请求的上下文引擎 v6。
- **客户保护**：确定性的“别再联系我”硬性停发、客户来信必有回复、删除后联系键拦截，解除只能由负责人执行。
- **承诺、商业事件与优惠**：按证据推进的承诺履约、签名商业事件、费用与关键结果、只能从目录发放并在派发时核对预算的优惠。
- **负责人工作台**：按角色的页面与受治理操作、人工接管与员工回复、审计。
- **隐私与数据生命周期**：按数据类保留、客户与消息删除及恢复后重放、受治理导出。
- **运维**：指标与告警规则、备份清单、恢复日志与恢复围栏、无豁免的迁移门槛、本地发布工具（清单、签名、验签、回滚检查）、本地 CI 控制器、开源合规检查。
- **运行时**：独立网络命名空间中的 Pi Durable Agent Host、多进程 guard、授权有界重试、多客户消息 relay。

## 不包含的内容与已知限制

权威清单见 [docs/ARCHITECTURE.md](../ARCHITECTURE.md) §6.2 与 [CHANGELOG](../../CHANGELOG.md) 各节“已知限制”。截至本草稿：

- **尚未部署**：双机部署（NX-032 切片 5）和部署环境的备份演练（NX-035）尚未执行；服务器步骤只能由负责人执行。
- **没有真实外发渠道**：真实派发开关默认关闭；外部效应只在本地和合成 provider 上验证过。
- **受控真实试运行尚未进行**：受控交互运行入口与 real driver 都已实现（driver 提示人工操作者、只读观测结果，自身不发送），但真实试运行本身尚未进行；NX-037 验收（AT-071、AT-072）未完成。
- **容量**：v0.1 声明支持 **200 个客户**（负责人决定 D-a），持续来信速率为 <RATE>。负载验收（AT-060）尚未通过：来信速率口径待负责人决定；500 与 1000 客户不在 v0.1 的支持范围内。
- 优惠只有回环渠道且没有工作台页面；员工回复只支持 WebChat；模拟世界尚无 Twin；EvoOntology 未安装。

## 部署前提

- 按角色的两台主机：**APP_HOST**（网关、API、各 Worker、Agent Host）与 **DATA_HOST**（带 pgvector 的 PostgreSQL 18、Valkey 8.1）。地址、用户与路径来自私有配置，不属于发布内容。
- 部署前提：Agent Host 全局并发 ≤ 4、guard 4 个进程、应用连接池合计 ≤ 60 且 `max_connections` ≥ 80（由 `nexloop-doctor` 核对）。
- 镜像按已签名发布清单中的 digest 引用；真实模型凭据由运维方自带，没有凭据时只能使用显式测试模式。
- 见 [docs/OPERATIONS.md](../OPERATIONS.md) 与 [NX-032 部署运行手册](../implementation/NX-032-deploy-runbook.md)。
