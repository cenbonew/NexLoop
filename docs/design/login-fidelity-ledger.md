# 登录界面 fidelity 验证

设计是自选概念，未声称用户已批准。概念：nexloop-login-concept.png，1586×992；最终实际浏览器截图：login-desktop.png，同尺寸；login-mobile.png，390×844。使用 Chromium149.0.7827.55/Playwright CLI，page.screenshot scale=css。由于 IAB 不信任自有测试证书，改用显式配置独立 profile 的公共 localhost 测试证书，保留 TLS 验证。最终 QA 同回合通过 view_image 查看概念与两个最新截图。

| 检查 | 概念/规格 | 实际浏览器证据与处理 |
|---|---|---|
| 文案与顺序 | NexLoop、登录标题、副标题、账号/placeholder、密码/placeholder、登录、会话说明、页脚 | DOM实际10项完整匹配，无新增/删除/重命名/重排；placeholder包含在对照中 |
| 布局与容器 | 白色画布、开放表单、无外框卡片，桌面表单宽524 | 实际x575、width524；标题y245、输入y415/y543、按钮y639；无卡片、图片或多余导航 |
| 字体层级 | 标题44/55、品牌32/40、说明18/27、label17/24、caption15/24 | computed styles实测一致；所有输入与按钮使用系统sans，不留浏览器默认字体；生成图的抗锯齿/纹理不作为应用资产 |
| 调色与资产 | white、navy12233b、muted66758b、blue2463eb、borderE2E8F0 | CSS采用对应token；实际纯白、蓝色CTA和浅色边框；无未加载图片或图标替代，品牌为原生文本 |
| 间距与控件 | 64px桌面输入/按钮、圆角10/9、说明与CTA分隔 | 实测width524/height64；首轮页脚约低12px，bottom42→54后最终图与概念页脚对齐 |
| 移动适配 | 24px侧边距、32px标题、52px控件，无桌面水平偏移 | 390×844下三控件均342×52，document.scrollWidth不超过viewport；主内容与页脚不重叠，无裁剪 |
| 状态与操作 | 可访问表单、真实加载/错误/认证状态 | 错误密码显示真实401对应alert；登录/重载/退出及退出后重载在两个视口通过；无模拟登录/业务数据 |

首屏copy diff：通过。桌面/移动原生尺寸：通过。已修复可见偏差：页脚12px偏移；favicon404通过显式空favicon消除，不新增品牌图标。移动布局按预先记录的 responsive spec 延伸，并非另一份获用户批准的概念图。错误/加载/认证状态是规格中允许的功能延伸。生成图纹理与字体抗锯齿属于图像/原生字体渲染差异，应用坚持规格中的纯白、系统字体和token，不复制图片噪声。

最终界面已按自选设计忠实核验，当前登录视图未发现需修复的实质布局/文案/字体/资产问题。该结论仅覆盖登录界面与上述工作流，不能代替完整工作台、Host Run 或 S2 验收。
