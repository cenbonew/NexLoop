# NX-011 Session touch and CSRF refresh

Migration 0028 adds protected touch through the dedicated restricted identity operator. It locks the Session exclusively and holds App/Subject/credential/membership rows through commit, then reuses canonical current Session validation. Expected revision and exact command identity bindings are checked; seen_at must be monotonic, no later than DB clock and before both old expiry limits. Only last_seen_at/idle expiry and optional CSRF digest change; frozen touch semantics preserve revision and absolute expiry. No expired session can be revived. CSRF refresh atomically replaces the stored digest, without changing the Session bearer credential.

PostgresBrowserSessionUnitOfWork implements the actual frozen touch port and decodes the result before commit. Private Session codecs are shared between reads and writes; invalid results roll back. Rejections return CredentialInvalid and do not retry. Raw tokens are never persisted. This is a private adapter, with no new HTTP endpoint.
