# NX-011 canonical Session reads

Migration 0027 adds a protected dedicated-identity Session lookup by globally unique ID or token digest, constrained to the server-configured tenant/App. The repository reads at one repeatable-read read-only snapshot. Canonical current App revision, Human Subject status/revision, active LocalAccount binding/revision/session epoch/restriction and lock, active membership subject/revision/validity, Session revocation and idle/absolute expiry are checked. Reads mutate no persisted state; a future touch/rotate/revoke must revalidate at dispatch. Token and CSRF digests are decoded only inside the private adapter into SecretDigest32, with strict enum/datetime/tuple conversion for the frozen BrowserSession model. Raw bearer tokens are never persisted or logged.
