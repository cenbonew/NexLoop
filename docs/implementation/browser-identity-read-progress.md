# NX-011 canonical browser identity PostgreSQL reads

Added append-only 0021_browser_identity_canonical_reads.sql and browser_identity.py. A dedicated nexloop_identity operator role receives only control schema usage, exact migration-catalog metadata reads and one protected canonical read function. It receives no business schema access, direct account/subject/member/application table privileges or business Action functions. The identity pool verifies the actual session/current role, rejects elevated membership, verifies the exact catalog and closes owned connections; existing business open_core does not treat the identity role as an application/business role.

Persisted authentication state is separate from formal business objects: globally unique frozen Subject records, tenant/principal membership, local-account credential state and active Application revision bindings. Application/tenant/operator checks precede reads. FORCE RLS constrains tenant rows and global Subject visibility to that tenant's actual account or membership links. The reader is constructed with trusted realm configuration; it does not accept browser tenant claims. Local-account password hashes/history are stored separately from nonsecret JSON payload, decoded as EncodedPasswordHash objects and kept out of repr/public responses. No password or subject identity is synthesized to grant a service permission.

This is a canonical state/read boundary, not completed password authentication or SessionCreationUnitOfWork. Session creation must still atomically lock/reload these rows, revalidate every evidence binding, consume evidence and write the Session. No login endpoint or browser permission is enabled by this read-only foundation. No Memory fallback or permissive auth path is introduced.

Actual fresh PostgreSQL tests verify typed model/hash roundtrip and real Argon2 verification, reopen/current Subject revocation, two-tenant global Subject isolation, configured Application revocation, operator/role boundaries, direct auth/business table denial, elevated membership refusal and malformed model fail-closed behavior.
