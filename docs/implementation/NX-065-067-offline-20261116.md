## 7dc73560 初版缺口与修复（后续 P2 见末节）

`Acceptance.operator_action()` 在 CSRF 获取不是200时直接返回其 HTTP status。`groups_mapping()` 把这个值当作 Action status：后半段 CSRF403 可误记成“原 session 的 operator Action 已被权限拒绝”，前半段 CSRF500 或 Action500/502/504 又能被“不是401/403/503”的条件误记成阳性。

修复仅两条执行判断：CSRF非200返回 None（没有尝试 Action、不可归因）；权限阳性排除所有5xx（保留2xx–4xx且非401/403的既有不存在问题探针形态）。None 在报告中为 null，不能通过阳性或权限收窄断言。另同步方法注释和运行单判据。没有改真实授权、登录、会话撤销、角色清单、组映射或 back-channel 实现。

新文件 `tests/test_nx065_oidc_acceptance_offline.py` 只用内存 Response/Client/IdP 状态、预设 session HTTP 序列和记录式 sleep。禁止 http_client、read_private、TerminalIdp 交互、socket、Popen；不使用凭据/实际 IdP/JWT/数据库。它测试的是脚本如何解释给定证据，不是后台策略确实生效。
