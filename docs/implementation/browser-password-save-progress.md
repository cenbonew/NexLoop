# NX-011 existing-account password-state save

The dedicated restricted identity repository now implements the frozen SaveLocalAccountCommand port for existing active Human accounts. App and Subject are revalidated and locked; the canonical account row is locked, expected revision checked, and only password rehash plus failed-attempt/lockout reset is permitted. Account creation, profile/email/status/Subject/session-epoch changes and active-lock bypass are denied. The operator must equal the actual nexloop_identity session_user. Neither a business Action nor an account-administration endpoint is exposed by this authentication metadata function.

Migration 0024 is appended to the independent immutable catalog. Saving and a nonsecret audit event are atomic.
