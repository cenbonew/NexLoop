# NX-011 atomic reauthentication replacement

Migration 0030 adds a protected reauthentication wrapper over the existing canonical revoke and Evidence-backed create functions. It locks and matches the old Session's configured realm, token digest and expected revision, revalidates/revokes it, then inserts the new authenticated Session and consumes fresh Evidence in the same transaction. Any insert/unique/reply/commit failure rolls back all three writes. The private CreateBrowserSessionCommand port now honors its all-or-none replacement guard; no client endpoint is introduced.
