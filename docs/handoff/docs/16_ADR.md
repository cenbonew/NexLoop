## 需要独立ADR才能改变的事项

替换Harness、直接写EIOS底表、双事实库、共享SQLite多进程、取消RLS/Action授权、让模拟触达真实客户、依赖GitHub在线CI、修改已发布迁移、引入专有必需服务，都不是普通实现细节。

## 普通实现细节

UI组件微调、经过回归的连接池大小、批量提取窗口、具体只读检索排序参数、同一兼容线依赖补丁升级，可以通过普通PR＋测试和配置版本处理，不需要反复询问负责人。
