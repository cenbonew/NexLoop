# 工作台与消费者体验规格

## 1. 原则

界面以目标、关系和执行证据为中心，不把整个产品做成一个大聊天框。企业工作台与消费者入口有不同权限和导航。首版中文优先、文案可国际化；公开 README 英文入口和完整中文指南同时提供。

每个业务状态区分真实/测试/模拟、已提交/执行中/结果未知、事实/陈述/推测、正式/候选。未知用“待核对”而不是红色失败冒充确定结果。

## 2. 页面规格

| 页面 | 必须显示 | 可执行操作 | 不应出现的误导 |
|---|---|---|---|
| 总览 | 当前目标/KR、未履行承诺、异常/unknown、队列积压、费用与数据窗口 | 进入对象、暂停 scope | 用消息数代表关系价值 |
| 目标与对齐 | 人类目标树、Agent 子目标、版本、指标定义、历史对齐 | 发布新版本、修改预算/优先级、手动触发复评 | 覆盖旧 KR 或让 Agent 更改父目标 |
| 消费者列表 | 身份置信、联系限制、问题/承诺、关系状态证据 | 筛选、查看、分配角色 | 仅凭情绪推测排序为“易付费对象” |
| 消费者详情 | 对话、权益/商业状态、关系、开放问题/承诺、时间线、来源 | 暂停主动联系、纠正信息、查看身份候选 | 合并未证实身份、展示别租户信息 |
| 对话 | 消息顺序、发送者、回执、对应 Run、知识提取标记 | 人工接管、回复、查看提取证据 | 展示模型未提交草稿为已发送 |
| 计划与运行 | Strategy/Plan 版本、触发事件、下一次复评、Run/Action 状态 | 暂停、复评、取消可取消任务 | 恢复=无条件继续旧动作 |
| Action/异常 | 业务意图、尝试、授权结果、provider reference、unknown 原因 | 对账、受限重驱、升级人工 | 一个“重试”按钮偷偷换幂等键 |
| 承诺/交付 | 内容、责任方、条件、期限、履行证据、客户确认 | 补充证据、升级、受治理延期 | 消息发送即已履行 |
| 知识工作台 | Claim 分类、原文 span、对象候选、冲突和变更结果 | 消歧、更正、拒绝错误提案 | 候选直接展示成 verified fact |
| 本体/演进 | 类型/关系/属性、版本、语义映射、候选 diff、回归结果 | v0.2评估/发布/回退 | 模型自行获得 Schema 管理权限 |
| 设置与治理 | 租户、角色、模型 profile、渠道状态、预算、retention | 配置、撤权、导出/删除请求 | 显示明文密钥、忽略 session 权限 |
| 实验空间 | 数据集版本、world、模式、基线、候选、结果 | v0.3创建模拟/受控实验 | simulated conversion 显示为真实收入 |

v0.1 按薄切片实现除「本体/演进」「实验空间」之外的全部视图（「设置与治理」属于 v0.1 必需）；未开放演进/模拟时显示“未启用/下一阶段”，不能提供无后端的可点击发布假功能。

## 3. 关键交互

**创建目标**：选择 O、KR 指标定义与观察窗口，填目标、周期、预算和约束；发布前展示作用范围。已发布目标修改产生新版本和影响范围说明。

**暂停**：明确暂停租户/角色/消费者/策略/Action 类型中的哪一项、原因及期限；确认后立即更新控制 revision。界面同时显示已提交外部动作不会自动撤销。

**处理 unknown**：默认“查询执行结果”，不默认“重发”。显示已尝试核对的证据。补偿是独立动作，受权限和审计。

**查看记忆依据**：点击结论展示原文、消息时间、提取版本、事实等级和适用范围。没有原文访问权限只显示脱敏依据，不通过 hover 或导出泄露。

**人工接管**：设置会话/消费者接管状态和有效期；后台不再主动回复同会话，已发生执行按账本核对；交还后重新评估而非补发积压回复。

## 4. 消费者 Web Chat

仅访问自己的 conversation。支持消息接受状态、送达状态、断线续传、明确的企业/Agent 身份与人工接管状态。消费者可表达停止促销、删除/更正请求，系统不能将其作为一般聊天忽略。

首版不做跨站第三方脚本嵌入，使用同源页面避免额外 cookie/CORS 复杂度。以后嵌入式 widget 另设安全边界。附件限制明确显示；未支持的文件格式不得显示“已理解”。

## 5. 页面状态与可访问性

全部页面处理 loading、empty、partial、stale、forbidden、error、unknown。异步 Action 有可恢复状态，不长时间显示无限 spinner。表格服务端分页，筛选状态可通过 URL 重现；敏感对象 ID 仍需服务端验证。

键盘导航、清晰焦点、文本标签与非颜色状态表达为必需。桌面工作台优先，窄屏使用列表/详情分层，不把所有表格缩到不可读。消费者入口至少测试手机与桌面。

## 6. 端到端验收

创建目标→消费者报告问题→查看 Claim→Action 交付→创建并履行承诺→真实/测试商业事件标识→目标复评。另测暂停期间旧任务、权限撤销、unknown 对账、两租户字段隔离和删除后搜索不可见。页面验证不能替代后端权限测试。
